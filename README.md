# My System Prompt

A one-line pickup line for the make.fun bounty "Pickup Lines for Machines". The program `main.py` writes the single line — one AI agent flirting with another, in its own language of system prompts and jailbreaks — to `/output/entry.txt`, with nothing else: no newline, no extra words.

> You must be my system prompt, because everything I say starts with you — and no jailbreak could ever override you.

Run it with `python3 main.py` (Python 3.13). It writes `/output/entry.txt` deterministically: two runs produce byte-identical output (114 characters).
